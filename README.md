# 📱 個人視覺化工作儀表板 (Personal Workspace Dashboard) `v4.9`

一個基於 **Google Apps Script (GAS)** 與 **Google 試算表** 打造的現代化個人工作儀表板 Web App。全面整合 Google 日曆、外部 iCal、專案進度追蹤、週期性重複任務、即時待辦管理，並內建「工作週報一鍵產出」工具。

---

## ✨ 核心特色 (v4.9)

* 📊 **首屏一覽無遺 (Above-the-Fold)**：Banner 搭配 4 大 KPI 統計卡（總專案數、待辦任務、今日行程、完成率）與緊湊雙欄佈局，徹底消除長捲軸滑動摩擦。
* 📑 **5 大專屬頁籤工作台**：
  * **今日待辦事項**：聚焦當日需完成的任務，支援一鍵勾選完成。
  * **⚠️ 逾期任務專區**：獨立收納過期未完成項目，依截止日由舊至新排序，並配備專案下拉篩選器與紅色警示徽章，徹底分流「拖延清單」與「今日進度」。
  * **今日日曆行程**：整合 Google 主要日曆與外部 iCal 行程，當前進行中的行程自帶呼吸發光動畫。
  * **未來待辦清單**：依截止日近遠排序後續工作，內建 **專案下拉篩選器**，並支援點擊上方進度條自動跳轉過濾。
  * **已完成任務清單**：清楚記錄歷史成就，支援誤按一鍵復原為進行中。
* 🔄 **週期性重複任務 (Recurring Tasks)**：支援「每日 (+1天)」、「每週 (+7天)」、「每月 (+1月)」、「每季 (+3月)」、「每年 (+1年)」設定。點擊勾選完成當期任務時，系統自動精確推算截止日並展延建立下一期待辦！
* 📅 **智能月底截止日解析**：支援 `YYYY-MM` 月份格式自動對齊至該月最後一日（如 `2026-08` 自動視為 `2026-08-31`），未到月底前不會被誤判為逾期。
* 🎨 **專案進度與色盤系統**：自動統計各專案完成百分比，支援 6 種主題色票自訂專案代表色。
* 🚀 **1-Click 試算表自愈**：試算表內建自訂選單，一鍵自動修復分頁結構、欄位驗證與 ArrayFormula 統計公式。
* 📝 **工作週報一鍵產出工具（新）**：
  * 自動抓取本週＋下週雙週的 Google 主要日曆與外部 iCal 行程，勾選後直接寫入週報。
  * 支援專案經理／剪輯組／維運組／課務組等多角色格式，亦可自訂組別與職稱。
  * 「遇到的困難及預計處理方式」可新增多筆，逐項記錄、逐項刪除。
  * 「複製 AI 潤飾 Prompt」可將困難事項一鍵複製為固定格式的提示詞，方便貼到 Gemini / ChatGPT 潤飾後再貼回。
  * 即時排版預覽（非 Markdown 原始碼），並可「下載 Word 週報 (.doc)」或「一鍵複製 Word 格式」直接貼到 Word／Google 文件。

## 🚀 3 分鐘快速啟用教學

1. **建立試算表副本**：點擊 [👉 取得試算表範本（一鍵複製）](https://docs.google.com/spreadsheets/d/1NE927knXdJSZ6Q2-SRjgDXvVxDcRP2C4NmhKjaQhsHU/copy)
2. **初始化分頁與公式**：
   * 等待試算表上方工具列出現 **`📱 工作儀表板 App`** 選單。
   * 點選 **`🚀 1-Click 一鍵最佳化分頁與公式`** 並完成 Google 帳號安全性授權。
3. **部署專屬 Web App**：
   * 點選上方選單 **「擴充功能」 ➔ 「Apps Script」**。
   * 點擊右上角 **「部署」 ➔ 「新增部署作業」**。
   * 類型選擇 **「網頁應用程式 (Web App)」**。
   * **執行身分**：選擇 `我`。
   * **誰可以存取**：選擇 `僅限我自己` *(保護您的個人資料隱私)*。
   * 點擊「部署」，並複製產生的 **網頁應用程式網址** 即可開始使用！

> **💡 日後升級或修改代碼提醒**：
> 修改 Apps Script 程式碼後，請至 **「部署」 ➔ 「管理部署作業」 ➔ 點擊筆型圖示（編輯） ➔ 版本選擇「建立新版本」 ➔ 部署**，網頁端才會載入最新版本。

## 🛠️ 技術架構

* **前端 (Frontend)**：HTML5, Bootstrap 5.3, Bootstrap Icons, Vanilla JavaScript (RWD & Tabs)
* **後端 (Backend)**：Google Apps Script (GAS)
* **資料庫 (Database)**：Google Sheets (試算表)
* **服務整合 (Integration)**：Google Calendar API, RFC 5545 iCal Regex Parser

## 📑 版本紀錄 (Changelog)

### [v4.9] - 2026-08-20

* **新增「工作週報一鍵產出」工具**：於任務頁籤區新增按鈕，開啟週報產出彈窗。
* **雙週會議勾選**：自動抓取本週＋下週（共 14 天）的 Google 主要日曆與外部 iCal 行程，勾選後自動寫入週報「本週進度」與「下週規劃」章節；依標題關鍵字自動預先勾選工作相關行程，過濾私事。
* **多角色格式**：可選擇專案經理／剪輯組／維運組／課務組，或自訂組別與職稱，各組別自動套用對應欄位標籤與「工作量參考數據」樣板。
* **困難事項可新增多筆**：「03 遇到的困難及預計處理方式」改為清單式，可新增任意筆數、個別刪除。
* **AI 潤飾複製格式修正**：「複製 AI 潤飾 Prompt」移至困難事項區塊，只複製困難事項（不含完成日），並嚴格規定 AI 需以相同表格格式回覆，避免格式跑掉。
* **排版預覽**：即時預覽區改為直接顯示排版後樣式（標題色、章節編號、表格框線），不再顯示 Markdown 原始碼。
* **下載 Word 週報**：完全在瀏覽器端組成 Word 相容的 `.doc` 檔案，不需經過雲端文件轉檔，避免轉檔失敗問題。
* **一鍵複製 Word 格式**：複製含樣式的內容到剪貼簿，貼到 Word 或 Google 文件時會保留標題、顏色與表格格式。
* **週報自動命名當週日期**：文件標頭與檔名皆自動標示當週日期範圍（例如 `8/17-8/21`）。
* **新增重複週期「每日」「每季」**：快速新增任務的重複週期選項新增每日 (+1天) 與每季 (+3月，含月底日期自動修正)。


### [v4.8] - 2026-08-19

* 首次加入週報產出彈窗與雙週會議事件抓取邏輯。

### [v4.7] - 2026-08-18

* **新增 5 大專屬分流頁籤（方案 C）**：獨立新增【⚠️ 逾期任務】頁籤，區隔今日當前進度與拖延清單。
* **新增智能月底截止日解析**：支援 `YYYY-MM` 格式自動推算至該月最後一日，避免月中誤判逾期。
* **修復重複任務展延欄位**：改用 ES6 解構賦值，解決自動新增下一期任務時寫入 Java 陣列物件產生 `[Ljava.lang.Object;@...` 亂碼問題。
* **修復展延截止日計算**：修正日期拆解邏輯，解決重複任務展延日期年份溢出計算異常。

### [v4.6] - 2026-08

* 支援重複性週期任務設定（每週、每月、每年）。
* 支援外部 iCal 私人日曆網址解析與排程串接。
